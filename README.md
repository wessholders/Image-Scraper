# Image Scraper

Small two-step workflow for downloading WMTS image tiles and merging them into georeferenced GeoTIFF mosaics.

## Files

- `image_scraper.py` downloads PNG tiles from the configured Pictometry WMTS URL into `Output_tiles`.
- `georeference_mosaic.py` reads downloaded tiles from `Output_tiles` and writes GeoTIFF mosaics into `Output_mosaic`.

## Requirements

Install the Python packages used by the scripts:

```powershell
pip install requests pillow numpy rasterio
```

`rasterio` can require GDAL-compatible wheels. If installation fails with plain `pip`, use a Python environment that already has geospatial packages installed.

## Usage

1. Edit the config block in `image_scraper.py`:
   - `BASE_URL`
   - `ZOOM_Level`
   - `TOP_LEFT`
   - `BOTTOM_RIGHT`
   - `OUT_DIR`

2. Run the tile downloader:

```powershell
py image_scraper.py
```

3. Edit the config block in `georeference_mosaic.py` if needed:
   - `TILE_DIR`
   - `ZOOM_Level`
   - `file_Prefix`
   - `OUTPUT_DIRECTORY`

4. Run the mosaic builder:

```powershell
py georeference_mosaic.py
```

## Outputs

- Downloaded tiles are written to `Output_tiles`.
- GeoTIFF mosaics are written to `Output_mosaic`.

These output folders are ignored by Git because they can become large and are generated by the scripts.

## Notes

- Tile filenames use this pattern: `{zoom}_{x}_{y}.png`.
- The mosaic script expects 256x256 PNG tiles and writes EPSG:3857 Web Mercator GeoTIFFs.
- PNG alpha is preserved as a fourth band in the output mosaic.
